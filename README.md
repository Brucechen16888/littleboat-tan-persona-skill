## 🚀 如何安裝與使用

### 1. 安裝至 Antigravity / Gemini CLI
直接將本資料夾複製到您的 skills 配置目錄：
`ash
# Windows
cp -r littleboat-tan-persona-skill %USERPROFILE%\.gemini\config\skills\littleboat-tan

# macOS / Linux
cp -r littleboat-tan-persona-skill ~/.gemini/config/skills/littleboat-tan
`

### 2. 安裝至 Claude Code / Claude Desktop
`ash
# macOS / Linux
cp -r littleboat-tan-persona-skill ~/.claude/skills/littleboat-tan

# Windows
cp -r littleboat-tan-persona-skill %APPDATA%\Claude\skills\littleboat-tan
`

### 3. 在對話中呼叫使用
安裝完成後，即可在支援的 AI 工具中透過 /littleboat-tan 或自然語言隨時調用：
- *「/littleboat-tan 請小船老師幫我診斷我的課程銷售漏斗，為什麼大家看了公開課卻不買單？」*
- *「/littleboat-tan 我想在【職場溝通】領域做一門線上課，請用『先賣後做 Pre-sell』幫我規劃驗證流程。」*
- *「/littleboat-tan 請用 90 分鐘 Webinar 模版，幫我撰寫一套能賣 NT$ 30,000 高客單課程的演講逐字大綱。」*
- *「/littleboat-tan 請為我的免費電子書引流品，寫一套 7 天自動化長青電郵追蹤序列。」*
